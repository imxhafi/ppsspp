# PPSSPP-X — GameHub Edition

## Mission
Preserve the existing PPSSPP emulator engine and build a powerful GameHub-style touchscreen control editor.

## Planned features
- Free drag-and-drop positioning for on-screen buttons
- Custom button sizes
- Adjustable button transparency
- Multiple saved control profiles
- Per-game control layouts
- Reset layouts to defaults
- Export and import layouts

## Development principles
1. Keep the PPSSPP emulation engine intact.
2. Extend the existing Android touchscreen-control system.
3. Keep changes incremental and testable.
4. Preserve compatibility with default layouts.
5. Validate on Android ARM64.

## Roadmap
1. Audit existing touchscreen input, layout, and persistence code.
2. Add control-editing mode and drag-and-drop.
3. Add button size and transparency settings.
4. Add profiles and per-game layouts.
5. Add reset, export, and import.
6. Build and test on Android ARM64.

## Current status
Project defined. Implementation has not started. No emulator-engine code has been changed.
